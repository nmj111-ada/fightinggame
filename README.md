# 文字格斗游戏（FightingGame）

一个基于 Java 的控制台（文字）回合制格斗小游戏。玩家先完成登录/注册，再分配属性点创建角色，然后与随机出现的敌人进行一场场回合制战斗，通过胜利不断变强。

纯 Java SE 实现，无任何第三方依赖，全部交互通过控制台输入输出完成，适合作为 Java 面向对象（继承、封装、集合、随机数、字符串处理）的练习项目。

## 功能一览

### 1. 账号系统

程序由 `App` 启动后进入登录注册页，主菜单提供 4 个选项：

| 选项 | 功能 | 规则 |
| --- | --- | --- |
| 1 | 登录 | 校验用户名、验证码、密码 |
| 2 | 注册 | 校验用户名与密码格式，两次密码一致 |
| 3 | 忘记密码 | 用户名 + 手机号验证后重置密码 |
| 4 | 退出 | 结束程序 |

- **注册**：用户名 3~6 位、只能由字母和数字组成、不能重复；密码 6~12 位字母数字，需两次输入一致；同时绑定手机号用于找回密码。
- **验证码**：随机生成 5 位验证码（4 位大小写字母 + 1 位数字）并打乱顺序。
- **登录安全**：密码最多可输错 3 次，第 3 次错误后该账号被标记为禁用，无法再登录。
- 用户对象自动生成形如 `heima12345` 的随机 ID 并存入集合。

### 2. 角色创建

- 玩家角色名为登录时使用的用户名。
- 共有 **30 点属性点**，可自由分配到 **生命值、攻击力、防御力、蓝量（MP）** 四项。
- 初始携带技能：普通攻击、强力一击、生命汲取、回复魔力。
- 初始背包物品：桃子 ×1、花酿鸡 ×1。

### 3. 战斗系统

回合制战斗，玩家每回合可选择一种行动：

| 行动 | 消耗 | 效果 |
| --- | --- | --- |
| 普通攻击 | — | 按攻击力造成伤害 |
| 强力一击 | 10 HP + 5 MP | 约 180% 攻击力的高额伤害 |
| 生命回复技能 | 5 MP | 随机回复 0~20 点生命 |
| 回复魔力 | 10 HP | 恢复 10 点 MP |
| 使用消耗品 | 1 个道具 | 回复道具对应的生命值 |

- **伤害公式**：`伤害 = 攻击力 - 对方防御力`，最低造成 1 点伤害。
- **敌人 AI**：每回合 50% 概率普通攻击、50% 概率释放技能；MP 不足时自动退化为普通攻击。
- **血量条**：以 20 格字符条（`█`/`░`）直观显示双方剩余血量。
- **失败嘲讽**：玩家被击败时，敌人会随机播放一句嘲讽台词。

### 4. 敌人

| 敌人 | 生命 | 攻击 | 防御 | 技能 | 技能效果 |
| --- | --- | --- | --- | --- | --- |
| 初级战士 | 80 | 15 | 10 | 猛击 | 150% 攻击力伤害 |
| 敏捷刺客 | 60 | 20 | 5 | 快速攻击 | 两次 50% 攻击力伤害 |
| 重装坦克 | 120 | 10 | 20 | 防御姿态 | 下回合受到的伤害减半 |
| 神秘法师 | 70 | 25 | 8 | 火球术 | 180% 攻击力伤害 |

每场战斗的敌人从上述列表中随机抽取。

### 5. 成长与掉落

- **战后回复**：击败敌人后回复 20~40 点生命。
- **属性成长**：每获得 3 场胜利，最大生命 +30、攻击 +5、防御 +3。
- **掉落系统**：击败敌人有 30% 概率掉落消耗品，道具在以下图鉴中随机抽取。

| 道具 | 回复生命 |
| --- | --- |
| 桃子 | 10 |
| 煎蛋 | 20 |
| 花酿鸡 | 30 |
| 黑背鲈鱼 | 40 |
| 白玉汤 | 50 |

- 每场战斗结束后可选择是否继续（`y` / `n`），游戏结束时结算总胜场。

## 项目结构

```
fightinggame/
├── src/
│   ├── App.java                        # 程序入口（登录 -> 游戏）
│   └── com/itheima/
│       ├── domain/                     # 数据模型
│       │   ├── Characters.java         # 角色基类：名字/HP/攻击/防御/MP，存活、回血、受伤
│       │   ├── HeroCharacter.java      # 玩家角色：技能列表 + 道具背包
│       │   ├── EnemyCharacters.java    # 敌人角色：技能、防御姿态、嘲讽、掉落
│       │   ├── Consumable.java         # 消耗品（回复道具）及图鉴
│       │   ├── User.java               # 用户：ID/用户名/密码/手机号/状态
│       │   └── VerificationCode.java   # 验证码生成
│       └── ui/                         # 界面（控制台）层
│           ├── Login.java              # 登录、注册、忘记密码
│           └── FightingGame.java       # 战斗主流程与回合逻辑
└── out/                                # 编译输出（已 gitignore）
```

## 运行方式

**环境要求**：JDK 8 及以上（IDEA 工程配置为 JDK 25），无需额外依赖。

**方式一：IDE**
用 IntelliJ IDEA 打开项目，运行 `src/App.java` 的 `main` 方法，然后在控制台按提示输入。

**方式二：命令行**

```bash
# 编译
javac -encoding UTF-8 -d out/production/fightinggame $(find src -name "*.java")   # Windows 可用 dir /s /b src\*.java 生成文件列表

# 运行
java -cp out/production/fightinggame App
```

> 提示：控制台需支持 UTF-8，否则中文与血量条方块可能显示异常。

## 技术要点

- 面向对象：`Characters` 作为基类，玩家与敌人通过继承扩展，`EnemyCharacters` 重写 `takeDamage` 实现「防御姿态」减伤。
- 集合框架：`ArrayList` 保存用户与敌人列表，`HashMap` 实现「道具名 -> 数量」的背包。
- 字符串与正则：用正则校验用户名/密码格式，`StringBuilder` 拼接技能表、背包与血量条。
- 随机数：验证码生成、敌人抽取、技能触发概率、掉落判定、嘲讽台词。
